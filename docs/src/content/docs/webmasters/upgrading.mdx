import { Steps } from '@astrojs/starlight/components';

<Steps>

1. Upload the new release's files over the old ones.
2. In **Configuration**, then **Plugins**, click **Deactivate** beside Reactions, then
   **Activate**.

</Steps>

Activating brings the database, templates, stylesheet and settings up to date. Reactions,
and every member's reaction to every post, are kept.
